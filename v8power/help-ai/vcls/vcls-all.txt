    [none]      Tühjendab ekraani praeguse teksti atribuudiga.
    n           Määrab teksti atribuudiks n.
    /A n        Määrab teksti atribuudiks n.
    /B color    Määrab taustateksti atribuudiks color (või
                väärtuse).
    /F color    Määrab esiplaani teksti atribuudiks color (või
                väärtuse).
    /G          Globaalne ekraani tühjendamine. (Vaikimisi)
    /L          Lokaalne ekraani tühjendamine. Tuvastab oma ümbruse
                ja tühjendab ainult selle. Tõenäoliselt kast, joon
                või midagi muud. Teil pole seda valikut tegelikult
                vaja. Sest te võite kasti lihtsalt uuesti
                joonistada.
    /K n        Kasutab piiride tuvastamiseks raamimärkide asemel
                n-i.
    TEXT        Tühjendab ainult teksti. Jätab kõik värvid puutumata
                ja eirab nende värviatribuute.
    EOL         Tühjendab ainult kursorist rea lõpuni.
    /C code     Tühjendab ASCII märgikoodiga täitmisega.
    /X column   Absoluutne ekraaniveerg tühjendamise alustamiseks.
    /Y row      Absoluutne ekraanirida tühjendamise alustamiseks.
    /W width    Tühjendatava ala kogulaius.
    /H height   Tühjendatava ala kogukõrgus.

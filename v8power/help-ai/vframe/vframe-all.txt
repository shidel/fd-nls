[none]          Nariše okvir, ki obdaja celoten zaslon.
/A n            Nastavi atribut besedila na n.
/B color        Nastavi atribut besedila ozadja na color (ali
                vrednost).
/F color        Nastavi atribut besedila ospredja na color (ali
                vrednost).
/X column       Stolpec zaslona za začetek okvirja.
/Y row          Vrstica zaslona za začetek okvirja.
/W width        Skupna širina okvirja.
/H height       Skupna višina okvirja.
/C              Sredini okvir vodoravno in navpično.
/T file ID      Poišče ID v file in ga obdela kot možnosti
                ukazne vrstice. Dodatne možnosti po tem
                stikalu izpolnijo spremenljivke %1-%9.
/P n            Nastavi neviden znak za polnilo n za textbox
                in optionbox.
style           Slogi okvirja so Single, Double, SingleSides,
                DoubleSides in Hidden.
shadow          Dodaj senco v 3D slogu.
textbox         Nariše okvir v slogu textbox z nekaj polnila
                in robovi.
optionbox       Nariše skrit slog optionbox za izbire znotraj
                okvirja.
